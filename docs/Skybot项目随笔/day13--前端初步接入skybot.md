## 前言

- 在经过之前的学习后，这个skybot已经基本达到工程实用阶段，当然后面也会对一些功能进行扩展和完善，现在就可以开始对接前端界面了；最终在前端界面增加一个可以调用这个skybot进行分析的按钮，用户在点击这个按钮直接可以调用接口进行返回相关信息。

```
前端商品详情页 -> Java 后端 -> Python Agent -> LLM -> 前端展示
```

**总结**

> **Day13 主要完成了 Skybot 与前端商品详情页的初步接入。之前 Agent 的能力主要通过 Apifox 测试验证，而本阶段将 AI 分析能力放到了真实页面中。用户在商品详情页点击“AI 分析这个商品”后，前端会携带当前商品的 `product_id` 请求 Java 后端的 Skybot 接口，再由 Java 调用 Python Agent 服务，最终由 Skybot 获取商品详情并调用 LLM 生成分析结果返回页面展示。这个阶段完成了前端、Java 后端、Python Agent 和 LLM 的完整闭环。当前 UI 和全站 AI 窗口还没有深入设计，后续可以统一优化。**
