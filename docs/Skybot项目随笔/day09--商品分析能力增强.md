## 前言

- day09旨在增强skybot的商品分析能力，也就是对商品的scence做出修改和补充，新增商品分析的场景，再新增增强skybot对相应商品的分析能力的具体Prompt函数，让skybot可以根据用户返回的商品id来进行合理的分析。

**具体逻辑**

```
用户传入 product_id
Skybot 调用 Java 商品详情接口
根据 scene 进入商品分析 Prompt
LLM 输出结构化购买建议
Apifox 测试成功
```


> **Day09 主要是在 Day08 商品详情接口接入的基础上，进一步增强 Agent 的商品分析能力。之前 Agent 只是能够根据 product_id 获取商品详情数据，而现在可以根据不同的 scene 场景选择不同的 Prompt，将商品详情数据和用户问题一起交给 LLM，由 LLM 从商品基本情况、价格合理性、描述风险、适合人群和购买建议等角度进行分析。这个过程说明 Agent 不只是简单调用接口拿数据，还可以通过 Prompt 设计把业务数据转化成更适合用户理解的智能分析结果。**

## 当前结果

- 已经实现skybot的商品分析能力增强。
